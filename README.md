# Customer Retention Platform

A Streamlit app that predicts which customers are likely to churn, explains why, and suggests
retention actions. Includes batch scoring, an interactive model report and a test suite.

## Features

| Tab | What it does |
|---|---|
| **Dashboard** | Filters, KPIs (churn rate, high-risk customers, monthly revenue at risk), churn charts, top-10 customers to save first |
| **Predict Churn** | Live score for one customer with a risk gauge, per-feature explanation, recommended actions and a contract what-if |
| **Batch Scoring** | Upload a CSV, score every customer, download the ranked result |
| **Model Report** | Metrics at an adjustable decision threshold, confusion matrix, ROC and Precision-Recall curves, model comparison |

## Quick start

```bash
pip install -r requirements.txt
python -m scripts.train_model          # trains and saves the model (recommended on first run)
python -m pytest -q                    # run the tests
python -m streamlit run app.py         # start the app
```

`python -m scripts.generate_data` re-creates the sample data (`data/customers.csv`) and the demo upload file
(`data/sample_batch.csv`). Skip it if you use your own data.

> Always run the commands from the project root (the folder that contains `app.py`).

## Using your own dataset

1. Replace `data/customers.csv`. Keep the columns `customer_id`, `tenure_months`, `monthly_charges`,
   `support_calls`, `contract`, `internet_service`, `payment_method`, `churn` (0/1)
   or edit `NUM`, `CAT` and `CATEGORY_OPTIONS` in `src/config.py`.
2. Run `python -m scripts.train_model`.
3. Optionally put a few rows (without `churn`) in `data/sample_batch.csv` for the batch demo.

## How the model is chosen

`train_model.py` compares Logistic Regression, Random Forest and Gradient Boosting with 5-fold
cross-validation on the training split. The simple, explainable Logistic Regression is kept unless another model
beats it by a clear margin in ROC-AUC. The winner is evaluated once on a held-out 20% test set.

## Docker

```bash
docker build -t churn-app .
docker run -p 8501:8501 churn-app
```

The image retrains the model during the build so it always matches the installed scikit-learn version.
